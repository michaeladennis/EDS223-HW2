# EDS223-HW2

## Redlining and Environmental Injustice

### Purpose
The purpose of this repository is to create maps and figures depicting redlining alongside bike and pedestrian safety observations.

### What's in the repo?
This repository contains a Quarto file to create figures and maps showing: historically redlined neighborhoods and summaries of the percent of observations within redlined neighborhoods within each HOLC grade. This repository also houses the necessary data, but it is hidden in the .gitignore file. For further information on the data and how to access it, see Data section below. The file structure in this repository is as follows:

```
EDS223-HW2
│   README.md
│   HW2.qmd
│   Rmd/Proj files    
│
└───.gitignore
     └───data
         └───ejscreen
         └───SWITRS_LA
         └───mapping-inequality
```

### Data
The necessary data is from [EPA EJScreen](https://www.epa.gov/ejscreen) website, the [University of Richmond Mapping Project](https://dsl.richmond.edu/panorama/redlining/#loc=5/39.1/-94.58&text=downloads), and the [Statewide Integrated Traffice Records System (SWITRS) database](https://tims.berkeley.edu/). The EPA EJScreen is no longer available, but can be found on an archived version of the website [here](https://pedp-ejscreen.azurewebsites.net/).
